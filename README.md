## 1. Application Description

Roséline is a modern e-commerce web application dedicated to flowers, luxury perfumes, and gift boxes.

The application provides customers with an elegant and user-friendly shopping experience. Visitors can explore different product collections, discover floral arrangements, search for products, add items to their favorites, and manage their shopping cart.

The boutique also offers a personalized message feature, allowing customers to add a special message to accompany their gifts.

The website features a soft and elegant visual identity, with a refined design inspired by flowers and femininity.

## 2. Technologies Used

The application is developed using the following technologies:

- **React.js:** Building the user interface using reusable components.
- **JavaScript:** Implementing application logic and interactivity.
- **Redux:** Managing the global application state.
- **HTML5:** Structuring the web pages.
- **CSS3:** Styling the application and creating a responsive design.
- **Vite:** Development environment and build tool.
- **Git & GitHub:** Source code management and version control.
- **Vercel:** Application deployment and hosting.

## 3. Main React Components

The application is organized into reusable React components:

| Component | Description |
|---|---|
| `Navbar` | Displays the navigation menu and links to the different sections. |
| `Hero` | Presents the boutique with a main banner and introduction. |
| `ProductList` | Displays the available products. |
| `ProductCard` | Shows product information, image, price, and shopping actions. |
| `Cart` | Displays selected products and the total price. |
| `Favorites` | Displays products saved by the user. |
| `SearchBar` | Allows users to search for products. |
| `Footer` | Displays contact information and useful links. |

## 4. Redux State Management

Redux is used to manage the application's global state and keep information synchronized between components.

The main state elements include:

- **Cart:** Stores the products added to the shopping cart.
- **Favorites:** Stores the products selected as favorites.
- **Search:** Stores the search input entered by the user.
- **Category:** Manages the selected product category.
- **Personalized Message:** Stores the recipient's name, message, and signature.
- **Promo Code:** Manages the promotional code entered by the customer.

These states allow different components to access and update shared application data.

## 5. Implemented Features

The main features of Roséline include:

- **Product Catalog:** Browse different collections, including flower bouquets, romantic bouquets, luxury perfumes, and signature bouquets.
- **Category Filtering:** Filter products according to their categories.
- **Product Search:** Search for a specific bouquet or perfume.
- **Shopping Cart:** Add products to the cart and view the order summary.
- **Favorites:** Save favorite products for later.
- **Personalized Messages:** Create a custom message with the recipient's name and signature.
- **Promotional Code:** Enter a discount code in the shopping cart.
- **Responsive Design:** Provide an interface adapted to different screen sizes.
- **Elegant User Interface:** A floral-inspired design with a soft and refined color palette.

## 6. Instructions for Running the Application

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Visual Studio Code

### Step 1: Clone the repository

```bash
git clone https://github.com/celina331/Roseline.git
```

### Step 2: Navigate to the project folder

```bash
cd Roseline
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start the development server

```bash
npm run dev
```

### Step 5: Open the application

Open the URL displayed in the terminal, usually:

```text
http://localhost:5173/
```
